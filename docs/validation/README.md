# Validation Reports

Use this folder for validation evidence that is too detailed for a story packet or `docs/TEST_MATRIX.md`.

Create a report when:

- preparing a release
- validating a high-risk story
- fixing a production bug
- completing deployment smoke tests
- reviewing accessibility, SEO, performance, or security evidence

Use:

```text
docs/templates/validation-report.md
```

Recommended naming:

```text
YYYY-MM-DD-short-scope.md
```

Each report should include command results, browser evidence, screenshot paths when available, console status, production URL when relevant, and remaining gaps.
